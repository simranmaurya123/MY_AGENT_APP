Heuristic Functions

1. Definition: A heuristic function, denoted \( h(n) \), estimates the cost of the cheapest path from node \( n \) to a goal node. It imparts problem-specific knowledge to the search algorithm.
2. Purpose: They guide the search process in algorithms like A* search or Greedy best-first search, estimating and prioritizing paths towards the goal to minimize search time.
3. Admissibility: An admissible heuristic never overestimates the cost to reach the goal. For example, straight-line distance is an admissible heuristic for route-finding.
4. Consistency: A heuristic is consistent if, for every node \( n \) and its successor \( n' \), \( h(n) \le c(n, a, n') + h(n') \). Consistent heuristics are always admissible.
